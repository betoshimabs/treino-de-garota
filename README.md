# BRABITA

Um diário pessoal de treino, feito para registrar o que aconteceu e acompanhar a própria história sem cobrança.

## Rodar localmente

```bash
npm install
npm run dev
```

## Verificar e gerar o site

```bash
npm run check
npm run build
```

O app é uma PWA local-first: os dados ficam no navegador da pessoa e podem ser exportados em **Eu → Seus dados**.

Publicado em [betoshimabs.github.io/treino-de-garota](https://betoshimabs.github.io/treino-de-garota/).
